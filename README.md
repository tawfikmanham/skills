# Product Design Skills

Two skills for reviewing product interfaces and practising design critique.

## Product Design Audit

Attach a screenshot to find out what works, what to improve first, and what to test in a prototype.

```sh
npx skills add tawfikmanham/product-design-critique-coach --skill product-design-audit --agent codex
```

[How it works](skills/product-design-audit/README.md) · [Read the skill](skills/product-design-audit/SKILL.md) · [See an example](skills/product-design-audit/README.md#example-a-checkout-screen)

## Product Design Critique Coach

Share your own critique to get feedback on how you explain the problem, connect it to the user's task, and give the designer a next step.

```sh
npx skills add tawfikmanham/product-design-critique-coach --skill product-design-critique-coach --agent codex
```

[How it works](skills/product-design-critique-coach/README.md) · [Read the skill](skills/product-design-critique-coach/SKILL.md) · [See an example](skills/product-design-critique-coach/README.md#example-rewriting-a-checkout-critique)

These commands use the [Vercel Skills CLI](https://github.com/vercel-labs/skills) and require Node.js 22.20 or later. Add `--global` to install across projects.
